## 一间从旧站搬来的小酒肆

这里保存的是 coderdogz 从 2021 年到 2022 年写下的技术笔记。内容集中在安卓逆向、抓包、Frida、Python、网络基础和日常开发环境的踩坑记录。

旧站原本由 Hexo 生成。它并没有消失，只是主题依赖的 Polyfill、jsDelivr 等外部脚本逐渐失效，导致每次打开都停在加载动画上。现在文章正文、分类、标签与插图已经整理进新的 Markdown 仓库，页面由更轻的静态生成器构建，不再依赖那套旧运行时。

> 做个俗人，贪财好色。  
> 但写下来的东西，还是想留得久一点。

## 关于迁移

这次迁移保留了原文的语气、代码和截图，只处理了几类影响阅读的旧格式问题：失效的图片外链、无法加载的前端脚本、原站配置错误产生的 `example.com` 链接。文章时间统一按北京时间保留，原来的分类和标签继续沿用。

## 关于仓库

所有文章都以 Markdown 保存在 [GitHub 仓库](https://github.com/coderdogz/blog)。新文章可以继续放进 `content/posts/`，提交后由 GitHub Actions 自动构建并发布。
