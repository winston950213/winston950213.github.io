在python中是没有字节数组这个概念的,但有时需要两者转换.其中的重点就是需要移动256位
```
def jb2pb(byte_arr):

 """
 java 字节数组转python字节数组
 :return:
 """

 return [i + 256 if i < 0 else i for i in byte_arr]
```
